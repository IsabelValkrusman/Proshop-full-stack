# ProShop

Full-stack e-commerce web application built with React and a backend API.

## About

ProShop is a full-stack online shopping application designed to provide a complete e-commerce experience.

The project includes both a responsive React frontend and a backend responsible for API functionality, product data, users, authentication, and orders.

## Features

- Product browsing
- Product details
- Shopping cart
- User registration and login
- User authentication
- Product reviews and ratings
- Order creation
- Order management
- User profile
- Responsive design
- REST API
- Frontend and backend integration

## Frontend

The frontend was developed with React and provides the main user interface for browsing products, managing the shopping cart, registering and logging in, and placing orders.

### Technologies

- React
- JavaScript
- HTML
- CSS
- React Router
- Redux
- Responsive Web Design

## Backend

The backend provides the server-side functionality and REST API used by the frontend.

It handles user accounts, authentication, products, reviews, and orders.

### Technologies

- Node.js
- Express.js
- REST API
- Database
- Authentication
